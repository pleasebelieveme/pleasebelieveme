아래 웹사이트의 디자인을 참고해서 쇼핑몰 메인 페이지를 HTML/CSS로 만들어줘.

참고 사이트:
https://wwit.design/2023/09/30/dotslashdash/

## 목표

참고 사이트의 전체적인 디자인 분위기, 레이아웃 구성, 여백, 타이포그래피, 색상 사용 방식, 카드 배치 방식 등을 분석해서 쇼핑몰 형태로 재구성해줘.

단, 참고 사이트를 그대로 복제하지 말고 **디자인 스타일과 분위기만 참고하여 새로운 쇼핑몰 UI로 제작**해줘.

## 가장 중요한 조건

이번 결과물은 **HTML과 CSS만 사용해서 제작**해줘.

다른 프레임워크나 라이브러리는 사용하지 마.

사용 금지:

* JavaScript
* React
* Vue
* Next.js
* Tailwind CSS
* Bootstrap
* npm
* Node.js
* 별도의 빌드 도구

파일은 반드시 아래 2개만 만들어줘.

```text
index.html
style.css
```

`index.html`에서 `style.css`를 연결해서 사용하고, 두 파일을 같은 폴더에 저장한 뒤 **index.html 파일을 브라우저로 바로 열면 완성된 쇼핑몰 화면을 미리볼 수 있도록 구성**해줘.

별도의 서버 실행, 패키지 설치, 빌드, 터미널 명령어 없이 사용할 수 있어야 해.

예를 들어 사용자가 아래처럼 파일을 저장하면 바로 실행되어야 해.

```text
shopping-mall/
├── index.html
└── style.css
```

이후 `index.html`을 더블클릭해서 Chrome 등의 브라우저에서 열었을 때 디자인이 정상적으로 보여야 해.

## 쇼핑몰 구성

메인 페이지에는 다음 요소를 포함해줘.

### 1. 헤더

* 쇼핑몰 로고
* NEW
* BEST
* SHOP
* ABOUT
* 검색 아이콘
* 장바구니 아이콘
* 로그인 메뉴

전체적으로 참고 사이트처럼 깔끔하고 여백이 많은 형태로 구성해줘.

### 2. 메인 비주얼

첫 화면에서 가장 눈에 띄는 Hero Section을 만들어줘.

포함 요소:

* 큰 제품 이미지
* 메인 카피
* 서브 카피
* SHOP NOW 버튼

참고 사이트처럼 큰 타이포그래피와 이미지를 적극적으로 사용하고, 일반적인 쇼핑몰 배너처럼 보이지 않도록 에디토리얼 디자인 느낌으로 만들어줘.

### 3. NEW ARRIVAL

신상품을 보여주는 영역을 만들어줘.

상품 4개를 배치해줘.

예시:

* Minimal Hoodie
* Basic T-Shirt
* Wide Denim Pants
* Canvas Bag

각 상품에는 다음 정보를 보여줘.

* 상품 이미지
* 상품명
* 가격
* 짧은 카테고리 또는 설명

### 4. BEST PRODUCT

대표 상품 하나를 강조해서 보여주는 섹션을 만들어줘.

이미지와 텍스트를 좌우로 크게 배치해줘.

포함 요소:

* 큰 상품 이미지
* 상품명
* 상품 설명
* 가격
* VIEW PRODUCT 또는 SHOP NOW 버튼

### 5. PRODUCT GRID

상품 6~8개 정도를 그리드 형태로 보여줘.

PC에서는 3~4열 정도로 배치하고 카드 디자인은 최대한 단순하게 구성해줘.

각 상품:

* 이미지
* 상품명
* 가격

상품 카드에 마우스를 올렸을 때 CSS만 사용해서 이미지가 살짝 확대되도록 만들어줘.

### 6. 브랜드 소개

쇼핑몰 브랜드를 소개하는 영역을 만들어줘.

예시 문구:

"Simple things, thoughtfully made."

또는 해당 디자인에 어울리는 브랜드 문구를 직접 작성해도 좋아.

이미지와 텍스트를 활용해서 패션 매거진이나 브랜드 룩북 같은 느낌으로 구성해줘.

### 7. 푸터

다음 항목을 포함해줘.

* 브랜드 이름
* Instagram
* Contact
* 이용약관
* 개인정보처리방침
* Copyright

## 디자인 방향

전체적인 디자인 키워드는 다음과 같아.

* Minimal
* Modern
* Editorial
* Fashion
* Clean
* Premium
* Typography-focused
* Image-focused

전체적으로 **패션 브랜드 공식 사이트나 편집숍 같은 분위기**가 나도록 만들어줘.

특히 참고 사이트처럼 웹페이지 자체가 하나의 포스터 또는 패션 매거진처럼 보이도록 구성해줘.

## 색상

기본적으로 다음 컬러를 중심으로 사용해줘.

* White
* Black
* Gray
* Off-white

포인트 컬러가 필요하다면 한 가지 정도만 제한적으로 사용해줘.

색상을 너무 많이 사용하지 마.

## 타이포그래피

큰 제목을 적극적으로 사용해줘.

제목은 화면에서 강한 인상을 줄 수 있도록 크게 배치하고, 본문과 상품 정보는 상대적으로 작게 만들어서 명확한 시각적 위계를 만들어줘.

영문 패션 브랜드 사이트와 비슷한 느낌을 목표로 해줘.

## 레이아웃

일반적인 쇼핑몰 템플릿처럼 모든 영역이 동일한 카드 형태로 반복되지 않도록 해줘.

섹션마다 레이아웃에 변화를 줘.

예:

* 이미지 크게 배치
* 텍스트 좌우 분할
* 비대칭 레이아웃
* 넓은 여백
* 큰 타이포그래피
* 상품 그리드

특히 **너무 많은 border-radius나 그림자를 사용하지 마.**

카드는 둥글고 귀여운 SaaS UI 느낌이 아니라, 패션 브랜드 사이트처럼 직선적이고 깔끔하게 만들어줘.

## CSS 인터랙션

JavaScript 없이 CSS만 사용해서 다음 효과를 구현해줘.

* 메뉴 hover
* 버튼 hover
* 상품 이미지 hover 확대
* 이미지 opacity 변화
* 링크 underline 애니메이션
* 부드러운 transition

애니메이션은 과하지 않게 만들어줘.

## 반응형

반드시 반응형으로 제작해줘.

### Desktop

* 최대 콘텐츠 너비 약 1400px
* 상품 3~4열
* 큰 Hero 이미지
* 큰 타이포그래피

### Tablet

* 상품 2열
* 이미지와 텍스트 크기 조정

### Mobile

* 상품 1~2열
* 텍스트 크기 축소
* Hero 이미지 자동 크기 조절
* 콘텐츠가 화면 밖으로 넘어가지 않도록 처리
* 모바일에서도 전체적인 디자인 분위기가 유지되도록 구성

CSS Media Query를 사용해서 구현해줘.

## 이미지 사용

이미지가 필요한 곳에는 브라우저에서 바로 확인할 수 있는 공개 이미지 URL을 사용해줘.

예:

* Unsplash
* images.unsplash.com

따라서 내가 별도로 이미지를 다운로드하지 않아도 `index.html`을 열었을 때 이미지까지 바로 보여야 해.

가능하면 패션, 의류, 모델, 제품 사진 위주로 선택해줘.

## 아이콘

검색, 장바구니 등의 아이콘이 필요한 경우 외부 JavaScript 라이브러리를 사용하지 마.

가능하면 다음 방법을 사용해줘.

* HTML 문자
* CSS
* inline SVG

아이콘 때문에 별도의 패키지를 설치하지 않아도 되도록 만들어줘.

## 코드 작성 방식

먼저 아래 순서대로 결과를 작성해줘.

### 1. index.html

`index.html`의 전체 코드를 하나의 코드블록으로 작성해줘.

중간 생략 없이 처음부터 끝까지 전체 코드를 제공해줘.

### 2. style.css

`style.css`의 전체 코드를 하나의 코드블록으로 작성해줘.

중간 생략 없이 처음부터 끝까지 전체 코드를 제공해줘.

HTML과 CSS에는 주요 영역을 알아보기 쉽도록 주석을 적절히 작성해줘.

## 미리보기 가능 여부 확인

코드를 작성한 뒤 스스로 다음 내용을 확인해줘.

* `index.html`과 `style.css`만 있는 상태에서 실행 가능한가?
* `index.html`을 브라우저로 바로 열었을 때 정상적으로 보이는가?
* CSS 경로가 올바른가?
* 이미지가 URL 방식으로 정상 표시되는가?
* JavaScript에 의존하는 기능이 없는가?
* npm 설치가 필요한 부분이 없는가?
* 모바일 반응형이 적용되어 있는가?
* 가로 스크롤이 불필요하게 발생하지 않는가?

문제가 있다면 수정한 뒤 최종 코드를 제공해줘.

## 중요

참고 사이트의 HTML/CSS 코드를 그대로 복사하지 마.

참고 사이트를 보고 다음 디자인 요소를 분석한 뒤 새로운 쇼핑몰 디자인으로 재구성해줘.

* 전체 레이아웃
* 콘텐츠 배치
* 타이포그래피
* 여백
* 이미지 비율
* 색상 조합
* 시각적 위계
* 섹션 구성 방식

최종 목표는 **HTML/CSS 공부용 예제가 아니라 실제 쇼핑몰 시안처럼 보이는 완성도 높은 웹페이지**야.

그리고 반드시 **HTML/CSS 파일 2개만으로 브라우저에서 즉시 미리볼 수 있는 형태**로 완성해줘.
