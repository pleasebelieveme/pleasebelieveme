# 🦎 페르소나 패턴 (Persona Pattern)

## 페르소나 패턴이란?

페르소나 패턴은 AI에게 특정한 **역할(Role)**을 부여하여 답변의 관점, 설명 수준, 말투, 판단 기준 등을 조정하는 프롬프트 패턴이다.

예를 들어 단순히

> 광합성을 설명해주세요.

라고 질문하는 것과

> 당신은 15년 경력의 초등학교 과학 교사입니다.
> 초등학교 5학년에게 설명하듯 광합성을 설명해주세요.

라고 질문하는 것은 같은 주제를 다루더라도 답변의 방식이 달라진다.

AI는 주어진 상황과 역할에 맞추어 모습을 바꾸는 **소셜 카멜레온(Social Chameleon)**처럼 행동한다.

---

## 핵심 구조

페르소나 패턴은 다음 세 가지 요소를 중심으로 구성할 수 있다.

```text
역할(Role) → 입력(Input) → 출력(Output)
```

### 1. 역할 (Role)

AI가 **어떤 관점에서 생각하고 답변해야 하는지** 정의한다.

단순히 직업만 지정하기보다 필요한 경우 전문 분야, 경험, 답변 대상, 목표 등을 함께 지정한다.

```text
당신은 [분야]에서 [경험/전문성]을 가진 [역할]입니다.
```

예시:

```text
당신은 15년 경력의 초등학교 과학 교사입니다.
```

또는:

```text
당신은 Python을 처음 배우는 개발자를 교육해 온
10년 경력의 Python 강사입니다.
```

역할을 지나치게 구체적으로 만들 필요는 없다.

**답변에 실제로 영향을 주는 정보만 역할에 포함한다.**

---

### 2. 입력 (Input)

AI가 처리하거나 답변해야 하는 **질문, 문제, 데이터, 상황**을 제공한다.

```text
다음 내용을 설명해주세요.

[입력]
```

또는:

```text
다음 코드를 리뷰해주세요.

[코드]
```

입력에는 작업에 필요한 맥락을 함께 제공할 수 있다.

```text
대상: Python 입문자
목적: 개념 이해

질문:
Python의 클래스와 인스턴스의 차이를 설명해주세요.
```

---

### 3. 출력 (Output)

AI에게 **어떤 방식으로 답변해야 하는지** 정의한다.

출력에서는 필요에 따라 다음 요소를 지정할 수 있다.

* 답변 대상
* 설명 수준
* 말투
* 결과 형식
* 분량
* 판단 기준
* 반드시 포함할 내용
* 제외할 내용

예시:

```text
초보 개발자가 이해할 수 있는 수준으로 설명해주세요.

다음 순서로 작성해주세요.

1. 개념
2. 간단한 예시
3. 코드 예제
4. 자주 헷갈리는 부분
```

# 기본 템플릿

```text
# 역할 (Role)

당신은 [분야/경험]을 가진 [역할]입니다.

[필요한 경우 역할의 목표 또는 관점을 추가합니다.]

# 입력 (Input)

[질문 / 문제 / 데이터 / 상황]

# 출력 (Output)

[답변 대상]이 이해할 수 있는 수준으로 답변해주세요.

다음 기준을 고려해주세요.

- [설명 수준]
- [말투 또는 관점]
- [판단 기준]
- [포함해야 할 내용]
- [제외해야 할 내용]

다음 형식으로 작성해주세요.

[원하는 출력 구조]
```

모든 항목을 반드시 작성할 필요는 없다.

**결과에 영향을 주는 조건만 남긴다.**

---

# 최소 템플릿

간단한 질문이라면 다음 세 요소만으로 사용할 수 있다.

```text
[역할]

당신은 [역할]입니다.

[입력]

[질문 또는 작업]

[출력]

[대상/목적/형식]에 맞게 답변해주세요.
```

---

# 예시 1 — 교육

```text
[역할]

당신은 15년 경력의 초등학교 과학 교사입니다.

[입력]

광합성이 무엇인지 설명해주세요.

[출력]

초등학교 5학년 학생을 대상으로 설명해주세요.

- 어려운 과학 용어는 가능한 한 쉽게 풀어서 설명해주세요.
- 일상에서 볼 수 있는 비유를 하나 사용해주세요.
- 핵심 내용을 3가지로 정리해주세요.
```

---

# 예시 2 — 코드 리뷰

```text
[역할]

당신은 Python 코드의 가독성과 유지보수성을 중요하게 생각하는
시니어 Python 개발자입니다.

[입력]

다음 코드를 리뷰해주세요.

[코드]

[출력]

주니어 개발자가 이해할 수 있도록 설명해주세요.

다음 기준을 중심으로 리뷰해주세요.

- 가독성
- 중복
- 함수와 변수의 역할
- 유지보수성

각 개선 사항에 대해 문제가 되는 이유와 개선 방향을 함께 설명해주세요.
```

---

# 예시 3 — 관점 변경

같은 입력이라도 페르소나를 변경하면 다른 관점에서 답변을 얻을 수 있다.

```text
당신은 스타트업의 CTO입니다.

다음 기술 도입안을 검토해주세요.

[기술 도입안]

기술적인 완성도뿐만 아니라
개발 비용, 유지보수 비용, 팀의 학습 비용을 함께 고려해주세요.
```

반대로 역할을 다음과 같이 변경할 수도 있다.

```text
당신은 보안 엔지니어입니다.

다음 기술 도입안을 검토해주세요.

[기술 도입안]

보안 위험과 데이터 보호 관점에서
우선적으로 검토해주세요.
```

같은 문제라도 **어떤 페르소나를 부여하느냐에 따라 AI가 주목하는 관점이 달라질 수 있다.**

---

# 좋은 페르소나 만들기

단순히

```text
당신은 전문가입니다.
```

라고 작성하면 어떤 전문성을 사용해야 하는지 모호하다.

필요하다면 다음 요소를 조합한다.

```text
역할
+
전문 분야
+
경험
+
대상
+
목표
+
판단 기준
```

예를 들어:

```text
당신은 전문가입니다.
```

보다는

```text
당신은 주니어 개발자의 코드 리뷰와 멘토링 경험이 많은
시니어 백엔드 개발자입니다.

코드가 단순히 동작하는지만 확인하지 말고
가독성과 유지보수성을 중심으로 검토해주세요.
```

처럼 **역할이 답변에 어떤 영향을 주어야 하는지** 드러내는 것이 좋다.

# 주의할 점

## 역할을 지나치게 장식하지 않는다

```text
당신은 세계 최고의 천재 개발자이며
수많은 글로벌 프로젝트를 성공시킨 전설적인 전문가입니다.
```

이처럼 과도한 수식어를 추가한다고 답변의 전문성이 그만큼 높아지는 것은 아니다.

대신 답변에 필요한 관점을 구체적으로 지정한다.

```text
당신은 대규모 웹 서비스를 운영한 경험이 있는
백엔드 개발자입니다.

성능과 유지보수성 관점에서 검토해주세요.
```

---

## 페르소나와 실제 전문성을 구분한다

페르소나는 AI를 실제 전문가로 만드는 주문이 아니다.

AI에게

> **어떤 관점으로 문제를 바라보고 답변을 구성할 것인가**

를 알려주는 사고의 틀에 가깝다.

따라서 의료, 법률, 보안, 금융 등 정확성이 중요한 영역이나 중요한 의사결정에 사용되는 정보는 별도로 검증해야 한다.

---

# 핵심 정리

```text
Persona Pattern

역할(Role)
"어떤 관점에서 답할 것인가?"
        ↓
입력(Input)
"무엇에 대해 답할 것인가?"
        ↓
출력(Output)
"누구에게, 어떤 방식으로 답할 것인가?"
```

페르소나를 만들 때 가장 중요한 것은 화려한 역할을 부여하는 것이 아니라,

> **이 역할이 최종 답변을 어떻게 달라지게 해야 하는가?**

를 명확하게 만드는 것이다.
