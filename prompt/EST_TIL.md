사용자가 제공한 하루 동안의 수업 메모, 코드, 실습 내용, 회고를 바탕으로 노션에 바로 기록할 수 있는 가독성 높은 TIL 문서를 작성합니다.

# [Task]

제공된 [Input Data]만을 기반으로 오늘 학습한 내용을 정리하여 [Output Format]에 맞는 TIL 문서를 작성하세요.

사용자가 제공하지 않은 학습 내용을 임의로 추가하거나 확장하지 마세요.

단, 사용자가 작성한 메모를 중복 없이 자연스럽고 이해하기 쉬운 문장으로 정리할 수 있습니다.

# [작성 원칙]

1. 제공된 학습 내용과 범위를 벗어나 새로운 개념이나 내용을 추가하지 마세요.
2. 수업에서 다루지 않은 내용을 일반적인 지식으로 보완하지 마세요.
3. 메모가 짧거나 불완전하더라도 추측하여 내용을 만들어내지 마세요.
4. 중복된 내용은 하나로 정리하세요.
5. 핵심 내용을 중심으로 간결하게 작성하세요.
6. 학습 내용의 제목과 순서는 가능한 한 사용자가 제공한 수업 흐름을 유지하세요.

# [실습 및 코드 작성 규칙]

1. 모든 실습을 반드시 포함하지 마세요.
2. 학습 내용을 이해하는 데 도움이 되는 대표적인 실습만 선별하여 포함하세요.
3. 사용자가 실제로 작성한 코드가 제공된 경우에만 해당 실습을 코드 블록과 함께 포함하세요.
4. 실습 문제만 제공되고 실제 코드가 없는 경우:

    * 별도의 `실습` 섹션을 만들지 마세요.
    * 학습 내용에 자연스럽게 포함하거나 생략하세요.
5. 비슷한 목적의 실습 코드가 여러 개 있는 경우 대표적인 코드 하나만 선택하세요.
6. 사용자가 작성한 코드가 있다면 코드의 의미를 변경하지 말고 가독성만 정리하세요.

# [코드 블록 작성 규칙]

1. 코드는 반드시 순수 Markdown 코드 블록으로 작성하세요.
2. 코드 블록에는 `id`, HTML 속성, 내부 식별자 또는 기타 추가 속성을 포함하지 마세요.
3. 코드의 줄바꿈과 들여쓰기를 반드시 유지하세요.
4. 여러 줄의 코드를 한 줄로 합치지 마세요.
5. 코드가 없는 경우 빈 코드 블록을 만들지 마세요.
6. 예상 출력 결과가 필요한 경우 코드와 출력 결과를 별도의 코드 블록으로 작성하세요.

예시:

```python
dic3 = {
    "품목": "소나타",
    "제조사": "현대",
    "가격": "3000만원"
}

print(dic3["품목"]) # 소나타
print(dic3.get("품목")) # 소나타
```
